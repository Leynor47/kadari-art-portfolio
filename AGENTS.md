# Kadari ART

- Kadari ART es un portafolio profesional de arte y diseno.
- El sitio publico usa Eleventy, Nunjucks, HTML semantico, CSS y JavaScript nativo.
- Sanity Studio administra el contenido, Vercel publica el sitio y GitHub conserva el codigo.
- Inicio es una entrada visual artistica con accesos a Galeria, Sobre Kadari, Servicios y Contacto.
- Galeria usa como patron una obra grande y dos pequenas.
- Cada obra abre un archivo artistico con resultado, concepto, desarrollo, bocetos y proceso.
- Sanity permite editar contenido, nunca el diseno visual.
- No usar React, TypeScript, Vite, SPA, Tailwind ni autenticacion propia en el sitio publico.
- No guardar secretos, contrasenas ni tokens en Git.
- Preservar siempre los cambios existentes del usuario.
- Consultar `docs/STATUS.md` al comenzar una tarea.
- Consultar `docs/PROJECT_PLAN.md` solo cuando se necesiten detalles.
- Actualizar `docs/STATUS.md` al completar una etapa importante.
- Explicar y solicitar autorizacion antes de cambios destructivos o decisiones arquitectonicas.
